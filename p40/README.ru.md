# Strata для AVX1 и Tesla P40

Проверенный Windows-билд: Ivy Bridge без AVX2/FMA/F16C, Tesla P40 sm61, CUDA12.9.
Последний профиль:50.28/49.95токена/с native decode;47.63/47.06 через прямой API.
Это прогретые короткий и4К запросы; скорость при заполненных128К не измерялась.

Скачайте ZIP из Releases, распакуйте, запустите INSTALL.cmd. Загрузка GGUF/mmproj/MTP
идёт напрямую с Hugging Face с докачкой и SHA-256. Исходный checkpoint не нужен.
Веса, pack, ключи, рабочие конфиги, логи и кэши в репу/ZIP не включены.
START.cmd запускает отдельную Windows task; STOP.cmd штатно дожидается drain.
INSTALL.cmd --workers14 --numa-node0 повторяет CPU-профиль измеренной машины;
для других машин NUMA0 нужно подтвердить отдельно, default=off.

Подробные таблицы и ограничения: BENCHMARKS.md. Рабочие патчи и проценты: PATCHES.md.
Четыре IQ/GR флага вместе дали+5.10%, B6/EXPDEC в отдельной серии+2.79%.
Эти проценты не складываются. Исторические16.4токена/с первой установки несопоставимы
с текущими50токенами/с как чистое A/B из-за других KV/MTP/thinking/cache настроек.

Лицензия кода — MIT; бинарные зависимости имеют собственные лицензии.
Microsoft VC Runtime устанавливается с сайта Microsoft, не копируется из частной среды.

на меньшей памяти и другом железе результат не гарантируется.
