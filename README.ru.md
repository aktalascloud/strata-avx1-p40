# Strata для AVX1 и Tesla P40

[English](README.md) | [Русский](README.ru.md)

Независимый форк [Strata](https://github.com/Niko1221/Strata), проверенный на Xeon Ivy Bridge без AVX2 и NVIDIA Tesla P40. Здесь собраны рабочие патчи, результаты настройки и готовый переносимый пакет для Windows.

Тестовая модель — **DavidAU Qwen3.8-Flash-Next IQ3_S**, с MTP Q2 и обработкой изображений на CPU.

**Измеренная скорость: 50,28 и 49,95 токена/с в движке; 47,63 и 47,06 токена/с с учётом накладных расходов API.** Это прогретые короткий запрос и запрос с закэшированным контекстом 4К, а не обещание такой скорости на любой задаче.

В пакет входит движок **0.1.48** на основе официального коммита [`5c8dd322528c`](https://github.com/Niko1221/Strata/commit/5c8dd322528cc84f68f461ad54a506b9da8fa8d4). Приведённые замеры сделаны **22 октября 2026 года** на версии 0.1.47, коммит `011c9e6`.

## Быстрый запуск в Windows

1. Скачайте переносимый ZIP и `SHA256SUMS.txt` из [раздела Releases](https://github.com/aktalascloud/strata-avx1-p40/releases).
2. Проверьте SHA-256 командой `Get-FileHash -Algorithm SHA256` и распакуйте архив в папку с коротким путём, например `C:\Strata-P40`.
3. Запустите **`INSTALL.cmd`**. Установщик проверит зависимости, скачает закреплённые GGUF, mmproj и MTP с Hugging Face **с докачкой и проверкой SHA-256**, затем подготовит pack из GGUF. Исходный checkpoint не нужен. Подтвердите запрос администратора Windows для регистрации задач запуска и управления; пароль не сохраняется.
4. Запустите **`START.cmd`**. Strata работает через отдельную задачу Windows. Для штатной остановки используйте **`STOP.cmd`**; если запрос ещё выполняется, дождитесь его завершения и повторите остановку.
5. Откройте `http://127.0.0.1:8093/`. Базовый адрес OpenAI-совместимого API: `http://127.0.0.1:8093/v1`.

Для этой сборки AVX1/P40 используйте CMD-файлы из релизного архива. **`CHECK.cmd`** проверяет целостность пакета без загрузки модели, запуска сервера и регистрации задачи.

Автозапуск выполняется Планировщиком **через 45 секунд после загрузки Windows**, ещё до интерактивного входа. Codex и открытый терминал не требуются. После завершённой установки **`AUTOSTART.cmd`** позволяет повторно зарегистрировать задачи. Для разных папок создаются разные имена задач. Установщик и запуск не перезагружают Windows и не останавливают чужие службы.

В репозитории и архиве **нет весов модели, готового pack, API-ключей, личных конфигураций, логов, кэшей, компиляторов и SDK**. При необходимости установщик получает Microsoft Visual C++ Runtime с официального сайта Microsoft и проверяет подпись. Совместимый с P40 драйвер NVIDIA с поддержкой CUDA 12.9 нужно установить отдельно.

Объём загрузки — примерно **85,6 ГБ**. С учётом подготовленного pack рекомендуется около **100 ГБ свободного места**. Проверенная система имеет **256 ГиБ RAM и 24 ГиБ VRAM**; работа на меньшем объёме памяти отдельно не подтверждена.

На проверенной системе с 16 видимыми логическими процессорами и GPU на NUMA-узле 0:

```bat
INSTALL.cmd --workers 14 --numa-node 0
```

Перед выбором узла проверьте размещение своей GPU. По умолчанию установщик **не задаёт NUMA-предпочтение**. Отдельную папку для скачанных весов можно указать параметром `--models-dir`.

Для отдельной установки выберите свободный локальный порт, например `--port 8094`, при первом запуске установщика. По умолчанию используется **8093**. Существующая конфигурация сохраняется: новый параметр её не перезаписывает. После переноса установленной папки нужно заново сформировать локальную конфигурацию и зарегистрировать задачи для нового пути.

## Реальная производительность

Тестовая система: **2 × Xeon E5-2697 v2**, 16 видимых логических процессоров, 256 ГиБ RAM, **Tesla P40 24 ГиБ**, Windows x64, драйвер NVIDIA 582.70. Используются Clang O3 с настройкой под Ivy Bridge и CUDA 12.9 для **sm_61**.

| Задача | Генерация в движке | Полный запрос через API | Первый токен рассуждения |
|---|---:|---:|---:|
| Короткий запрос, 128 сгенерированных токенов | 50,2789 токена/с | 47,6324 токена/с | 0,172 с |
| Закэшированный контекст 4К, 128 токенов | 49,9454 токена/с | 47,0583 токена/с | 0,188 с |

Обработка нового префикса 4К измерялась отдельно: **262,25 токена/с**. Скорость при полностью заполненном контексте 128К **не измерялась**. В количество сгенерированных токенов входят и токены рассуждения.

### Сопоставимые сравнения

| Изменение | До | После | Прирост |
|---|---:|---:|---:|
| Совместно IQ staging, QFUSE и быстрый путь GR | 47,9760 токена/с | 50,4235 токена/с | **+5,101%**, или +2,4475 токена/с |
| B6 + EXPDEC, I64/J96 | 48,7498 токена/с | 50,1116 токена/с | **+2,793%**, или +1,3617 токена/с |
| 14 CPU workers вместо 8, NUMA-узел 0 | 47,9257 токена/с | 49,5107 токена/с | **+3,307%** |
| Предпочтение памяти NUMA-узла 0 вместо стандартного размещения | 48,8009 токена/с | 49,5107 токена/с | **+1,454%** |

Оценка — гармоническое среднее двух медиан скорости движка. Сравнения выполнены в разных сериях: **их проценты нельзя складывать или перемножать**. Каждый вариант проходил два прогревочных и пять измеряемых запросов на каждой задаче: 128 токенов, temperature 0, seed 12345 и авторский режим high/xhigh.

При первой установке было 16,4 токена/с, но с другими KV, контекстом, MTP, режимом рассуждения и состоянием кэша. Это историческая отметка, а не чистое сравнение эффективности отдельных патчей.

## Патчи и выбранные параметры

| Компонент | Что делает |
|---|---|
| [`native-ivybridge-p40.patch`](p40/patches/native-ivybridge-p40.patch) | Сборка Clang O3 под Ivy Bridge без AVX2, FMA и F16C в базовом коде; возможность отключить CPU pinning; предпочтение памяти NUMA в Windows; дополнительные проверки CPU и CUDA Graphs. Уже применён в этом форке. Широкие ядра сохраняют проверки ISA. |
| [`pascallama-sm61.patch`](p40/patches/pascallama-sm61.patch) | Настройка Pascal DP4A MMQ: плитки J96 и подсказки разворачивания циклов. Применяется только к приватной копии закреплённого GGML. Основа — [pascallama.cpp](https://github.com/madsteph74/pascallama.cpp). |
| B6 = 1, EXPDEC = 1 / R = 1, I64/J96 | Выбранное совместное сочетание ядер. Значение B6 = 1 означает две строки. |
| IQ staging, QFUSE и быстрый путь нормализации GR | Включены вместе после прямых и графовых проверок. Часть быстрых путей уже присутствует в официальной Strata. |
| DenseF32 | Экспериментальный режим. Полный стандартный набор из 5201 проверки пройден; наблюдавшиеся +0,12% prefill находятся в пределах погрешности измерения. |

Сохранены **131072 токена, KV q4_0, авторский xhigh, MTP Q2 с двумя draft-токенами, prefill 512, PLE в RAM, PCIe auto и обработка изображений на CPU**. Для MTP используются `--spec 3` и `--spec-min-p 0.25`. Пропуск экспертов отключён.

PGO, ThinLTO, дополнительная CUDA-векторизация и I128 проверялись отдельно и в сочетаниях. Выбран обычный O3 с I64/J96. Отдельный процент ускорения для каждого небольшого изменения кода не заявляется.

Текущая сборка прошла **23 численные и графовые проверки**, включая полный тест DenseF32 из 5201 случая и BF16 finite/NaN в обычном режиме и CUDA Graphs. Другие GPU и бэкенды этой Windows-сборкой не квалифицированы. Конфигурация не меняет CPU affinity, частоты, лимиты мощности, вентиляторы и термозащиту.

Добавлены **11 проверенных исправлений из PR**: запуск и время жизни ресурсов Windows/CUDA, MTP, потоковый OpenAI API и BF16. [Изменения, авторы и границы проверки](p40/COMMUNITY-FIXES.md). Таблица скорости выше относится к исходникам `011c9e6`: на новом релизе скорость повторно не измерялась.
